# My Zombies - Visual Novel Game

An 18+ apocalyptic zombie-themed visual novel game created with Ren'Py engine.

## About the Game

Set during the first outbreak of the apocalypse in a Japanese high school, this visual novel immerses players in a dark, immersive zombie survival story.

## UI Theme

All UI screens have been redesigned with an apocalyptic aesthetic:
- Blood red accents (#CC0000) for danger and urgency
- Decay yellow (#E8D000) for caution elements
- Terminal green (#00FF00) for technical details
- Dark grays (#1a1a1a) for worn, abandoned atmosphere

### Optimized for 1280x720p resolution

## Version
0.1 - Initial Apocalyptic UI Redesign Release

## Files

- **gui.rpy** - Color definitions and theme configuration
- **screens.rpy** - All UI screen styling
- **script.rpy** - Game script and story
- **options.rpy** - Game configuration

## Installation

1. Ensure you have Ren'Py installed (8.5.3 or later recommended)
2. Extract the files to your game directory
3. Launch with Ren'Py launcher
